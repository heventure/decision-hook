# Decision Hook

在编码智能体的固定工作流节点调用类型化决策模型。首版聚焦 Pi 中的 Vitest 失败分诊，使用本机 LM Studio。它尝试把一次有限选项的判断交给独立模型，然后把结果交回主智能体继续处理。

**项目状态：设计阶段。** 按当前设计，分类建议不会执行命令、授权操作、改变测试的成功或失败状态。首版插件和安装命令待开发，暂无插件效果数据。

## 首版工作流

1. Pi 取得一次已经执行完成的 Vitest 工具结果。插件识别目标运行并提取有界的诊断信息，保留原始工具结果。
2. 明确的运行器或断言信号由规则处理。其余满足触发条件的结果交给本机决策模型，返回断言失败、环境异常或证据不足。
3. 输出标签、来源及必要的回退原因。端点不可达、响应无效、超时或证据不足时，主智能体接续正常处理。

## 计划支持的环境
